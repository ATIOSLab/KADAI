KADAI — BRAND ICON PACK
=======================
Konsep : K dengan kaki lengkung wajan. Titik amber = percikan bara (juga titik huruf i pada wordmark).
Warna  : Slate #020617 / #0F172A, Ember #EA580C, Glow #FB923C, Amber #F59E0B, Putih #FFFFFF
Font   : Bahnschrift Bold (tracking -4.5%), wordmark lowercase "kadaı" (i tanpa titik + titik amber).

ISI
---
svg/                    Vektor master (app icon, mark, mono). Skala tanpa batas.
png/app-icon/           App icon 16-1024 px: dark, light, orange, circle.
png/mark-transparent/   Logo K saja, latar transparan, untuk di atas warna/foto.
png/mono/               Hitam / putih / oranye satu warna.
png/lockup/             Logo + wordmark, horizontal & stacked, versi on-dark / on-light (+ transparan).
favicon/                favicon.ico, favicon.svg, apple-touch-icon, android-chrome, site.webmanifest, head-snippet.html
mobile/ios/             Seluruh ukuran AppIcon iOS (tanpa sudut membulat, iOS memotong sendiri).
mobile/android/         Launcher icon per density + adaptive foreground 432 px + warna latar.
social/                 Avatar, OG image 1200x630, header X, banner LinkedIn, wallpaper, story 9:16.

ATURAN PAKAI
------------
- Ruang aman di sekeliling logo minimal setengah lebar batang K.
- Ukuran minimum: app icon 16 px, lockup horizontal 120 px lebar.
- Jangan meregangkan, memutar, atau mengganti warna gradasi.
- Di atas latar terang pakai varian on-light; di atas latar gelap pakai on-dark; satu warna pakai mono.
- File lockup berupa PNG (font dirender). Untuk lockup vektor, buka wordmark di Figma/Illustrator dengan Bahnschrift Bold lalu outline.
